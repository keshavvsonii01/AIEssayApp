# AI Essay Generator

> AI-powered essay generation and writing assistant built with Next.js.

AI Essay Generator is a web application that uses generative AI to help users create essays based on their requirements.

The application combines AI-powered content generation with an interactive writing experience, making it easier to generate, refine, and work with written content.

## ✨ Features

- 🤖 **AI-Powered Essay Generation**
  - Generate essays using generative AI based on user-provided requirements.
  - Create content dynamically instead of starting from a blank page.

- ✍️ **Interactive Writing Experience**
  - Work with generated content through an integrated editor.
  - Refine and modify generated essays as needed.

- ⚡ **Dynamic AI Integration**
  - Connects the application to a generative AI model for content generation.
  - Designed around prompt-driven workflows.

- 🎯 **Simple User Experience**
  - Focused interface for generating and working with AI-assisted written content.

## 🛠️ Tech Stack

- **Framework:** Next.js
- **Language:** TypeScript
- **Frontend:** React
- **AI:** Google Gemini API
- **Editor:** React Quill
- **Styling:** CSS

## 🚀 Getting Started

### Prerequisites

Make sure you have Node.js and npm installed on your machine.

### Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/keshavvsonii01/AIEssayApp.git
   cd AIEssayApp
   ```

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Set up Environment Variables**

   Create a `.env.local` file in the root directory and add your Gemini API configuration:

   ```env
   GEMINI_API_KEY=your_api_key_here
   ```

   > **Note:** Never commit API keys, credentials, or other sensitive information to the repository.

4. **Start the development server**

   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🧠 How It Works

The application follows a simple AI-assisted writing workflow:

```text
User Requirements
       ↓
   AI Prompt
       ↓
  Gemini API
       ↓
Generated Essay
       ↓
Interactive Editor
       ↓
     Refine
```

The goal is to combine generative AI with a familiar writing workflow so users can move from an idea to editable content quickly.
